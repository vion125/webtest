實戰演練 3 步驟

  1. 部署並觸發

    將此應用部署至 AWS EC2 或 ECS，在網頁端將核心拉滿並啟動燒機，使其持續 3-5 分鐘。

  2. 前往 CloudWatch 查看

    進入 AWS Console ➜ 搜尋 CloudWatch ➜ 點擊 Metrics ➜ All metrics ➜ EC2 ➜ Per-Instance Metrics，勾選您的執行個體並尋找 CPUUtilization 指標。

  3. 建立 Alarm 告警練習

    點擊指標旁的鐘頭圖示 ➜ 設定臨界值（例如 > 70%）➜ 設定當達到臨界值時，透過 Amazon SNS 發送電子郵件或簡訊通知您，完成自動化告警閉環！

⚠️ 安全提示：本系統內建「雙重安全釋放鎖」。除了隨時可點擊「停止暴增」釋放外，若您意外關閉網頁或斷線，背景執行緒只要偵測到時間耗盡，也會強制 Kill 燒機進程，讓您在 AWS 實戰時絕不會因為意外超時而造成高額帳單。
