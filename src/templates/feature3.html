💡 安全提示：本系統完全遵循 AWS 雲端權限最佳實踐，在任何程式碼、環境變數或組態檔中，皆無硬編碼 AWS 存取金鑰。本機開發時透過 local credentials 自動模擬，當部署至 AWS ECS 容器時，會自動透過 ECS Task Role 進行零憑證安全鏈介接。

如何部署至真實 S3？

  1. 在 AWS 上建立名為 ckc101_28_2 的 S3 Bucket。
  2. 建立一個 IAM Role，授予 S3 Bucket 的讀寫權限（例如 s3:PutObject、s3:GetObject、s3:DeleteObject、s3:ListBucket）。
  3. 將此 Role 綁定至您的 EC2 執行個體或 ECS 任務定義中。
  4. 本程式容器啟動後，將會自動載入 Role 憑證，無縫介接真實 S3 Bucket！
